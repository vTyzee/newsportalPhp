# Newsportal

PHP ja MySQL abil loodud uudisteportaali õppeprojekt.

Projekt kasutab MVC arhitektuuri ning MySQL andmebaasi.

## Tehnoloogiad

- PHP
- MySQL
- PDO
- HTML
- CSS
- MVC

## Projekti struktuur

- `controller` – kontrollerid
- `model` – andmebaasi andmete töötlemine
- `view` – kasutajaliidese vaated
- `route` – marsruutimine
- `inc` – andmebaasi ühendus
- `public` – CSS ja muud avalikud failid

## Käivitamine

Projekt on loodud töötamiseks XAMPP keskkonnas.

1. Paiguta projekt `xampp/htdocs` kausta.
2. Käivita Apache ja MySQL.
3. Impordi `newsportal` andmebaas.
4. Ava projekt brauseris localhost kaudu.
